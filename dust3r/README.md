# DUSt3R Module

This directory contains the DUSt3R (Dense and Unconstrained Structure from Motion) codebase.

## Source

**This code was copied from the MASt3R repository** (which includes DUSt3R as a dependency).

This is a local copy of the DUSt3R codebase included in Dark3R to ensure compatibility and avoid external dependency issues. Please refer to the original DUSt3R repository for:
- Full documentation
- Latest updates
- Issue tracking
- License information

## Usage in Dark3R

Dark3R uses DUSt3R utilities for:
- Image loading and preprocessing
- Geometry operations (transformations, point cloud operations)
- Post-processing utilities

## Note

This directory should be treated as read-only for Dark3R purposes. Any modifications to DUSt3R code should be made in the original repository and then copied here if needed.
