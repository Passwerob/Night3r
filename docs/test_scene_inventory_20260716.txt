Night3R test-scene inventory
Audit date: 2026-07-16

This document separates current paper evaluation roots, auxiliary stress-test
roots, and archived roots.  A directory named "test" is not automatically a
strict held-out test set; scene overlap with the checkpoint's training root is
reported explicitly below.

6. Table 7 audit conclusion
===========================

Table 7 did load data through the current DSEC_test and
MVSEC_outdoor_night2_test filesystem roots.  The CLI --data-root correctly
overrode the training root stored in the evaluation config, and all compared
methods used identical ordered sample IDs.

However, Table 7 is not an all-test-scene evaluation:

    1. DSEC uses 128/612 available test pairs.
    2. MVSEC uses 128/288 available pairs and only partially covers 3/6 scenes.
    3. The six current MVSEC scenes overlap the full MVSEC root used by the
       final MVSEC-only 1k checkpoint.
    4. The 40-scene DL3DV evaluation pool is absent from Table 7.

Therefore the existing Table 7 should be described as a fixed-subset darken
evaluation, not as a full strictly held-out multi-dataset test benchmark.
